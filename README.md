# AI 課程｜教學靈感庫

整合教師互動網站與 AI 教學資源的繁體中文網頁，共 149 筆資源。

## 功能

- 搜尋網站、老師、單元或資源編號。
- 按主題、資源類型與來源篩選。
- 收藏常用資源，儲存於使用者的瀏覽器。
- 查看來源頁碼與整理備註。
- 複製互動網站製作提示詞。
- 手機與電腦皆可使用。

## 本機使用

下載或複製此儲存庫後，直接開啟 `index.html`。也可使用任何靜態網頁伺服器。

## 檔案

- `index.html`：網頁結構與提示詞筆記。
- `style.css`：桌機與手機版排版。
- `app.js`：搜尋、篩選、收藏及提示詞複製功能。
- `data.js`：149 筆整理資料。
- `resources.md`：完整 Markdown 清單。
